# 🍫 SQL – Awesome Chocolates Data Analysis

A SQL practice project using the **Awesome Chocolates** database. This project covers basic SQL queries, filtering, sorting, calculated columns, conditional statements, date functions, and grouping data using MySQL.

---

## 📊 What This Project Does

This project demonstrates fundamental SQL concepts using Sales and People tables.

It helps to understand:

- Database and Table Exploration
- SELECT Statement
- Selecting Specific Columns
- Calculated Columns
- WHERE Clause
- ORDER BY
- AND / OR Operators
- BETWEEN Operator
- IN Operator
- LIKE Operator
- CASE Statement
- Date Functions
- GROUP BY

## 🧠 Key Concepts Covered

**1. Database Selection**

Using `USE` to select the database.

**2. Retrieving Data**

Using `SELECT` and `SELECT *` to display records.

**3. Calculated Columns**

Performing calculations such as `Amount / Boxes`.

**4. WHERE Clause**

Filtering records based on conditions.

**5. ORDER BY**

Sorting records in ascending or descending order.

**6. Date Functions**

Using `YEAR()` and `WEEKDAY()` to filter and analyze dates.

**7. Operators**

Using `AND`, `OR`, `BETWEEN`, `IN`, and `LIKE`.

**8. CASE Statement**

Creating conditional categories based on sales amounts.

**9. GROUP BY**

Grouping records by team and counting employees.

## 📈 SQL Operations Performed

| Operation  | Purpose                   |
|------------|---------------------------|
| `SELECT`   | Retrieve data             |
| `WHERE`    | Filter records            |
| `AS`       | Rename columns            |
| `ORDER BY` | Sort records              |
| `YEAR()`   | Extract year from date    |
| `WEEKDAY()`| Get day of the week       |
| `BETWEEN`  | Filter a range of values  |
| `IN`       | Match multiple values     |
| `LIKE`     | Search using patterns     |
| `CASE`     | Apply conditional logic   |
| `GROUP BY` | Group records             |
| `COUNT()`  | Count records             |
